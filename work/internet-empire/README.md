# Internet Empire

Build the internet from a **1995** garage startup through the **2030** AI era.

**Stack:** React, TypeScript, Tailwind, Zustand, Recharts, Three.js side stage, deterministic monthly sim.

**Dev:**

```bash
cd work/internet-empire
npm install
npm run dev
```

**Build:** `npm run build` → `dist/` copied to `public/play/internet-empire/` on site prebuild.

**Play (production):** [/work/internet-empire/](https://austinbuhltech.com/work/internet-empire/)
